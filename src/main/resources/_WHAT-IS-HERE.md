# Server settings file and web pages

application.properties = ALL server settings, including the DATABASE CONNECTION. static/ = web pages the server shows.

| File | What it is |
|---|---|
| `application.properties` | ALL server settings. DATABASE CONNECTION is here (spring.datasource...). Real passwords are NOT here - they are set on Render. |

Folders inside: `static/`, `templates/`

Lost? Open `START-HERE - where is what.md` in the main project folder.
