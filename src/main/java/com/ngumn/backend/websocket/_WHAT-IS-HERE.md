# Live messages to the app

Pushes updates to phones and browsers at once (alerts, status changes).

| File | What it is |
|---|---|
| `NgumnWebSocketHandler.java` | Broadcasts live updates (vehicle movement, alerts, emergency events) to every connected client (mobile app + admin dashboard). |
| `SimpleJson.java` | Tiny helper to wrap a broadcast payload as {"type" |
